# 8 核极端负载 edge_end 卸载验证

## 实验口径

- PC 可用核心：`60-67`，共 8 个核心。
- baseline：原始 Q4 GGUF `qwen.q4_0.gguf`，在 PC 的 8 个核心上执行 no-SVD decode。
- major-only：仍在 PC 上执行 no-SVD decode，但枚举 `p=1..7` 个低负载核心，取实测最快值作为对照。
- edge_end：`M=0;Phone=[0,28);PC=empty`，即不走 SVD，把完整 no-SVD decode 卸载到手机端执行。
- 背景负载：每个被占用 PC 核心启动 4 个 `stress-ng --cpu-method matrixprod` worker，并按表中 load 百分比施加。
- decode token 数：32。
- PPL：三条路径都使用 no-SVD 原始 Q4 模型，因此 PPL 不变，沿用 Q4 baseline sanity 值 `15.1424`。

## 汇总结论

- 满足筛选条件的场景数：`8`。
- 相对 baseline 提速：min `1.252x`，median `2.335x`，max `2.650x`。
- 相对 best major-only 提速：min `1.214x`，median `2.312x`，max `2.426x`。

## 可绘图 CSV

- `plot_edge_end_winners.csv`：严格筛选后的绘图数据。
- `raw.csv`：所有 baseline / major-only / edge_end 原始运行记录。
- `summary.csv`：每个场景的调度器选择结果。
